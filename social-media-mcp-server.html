Hosted MCP server

Social media MCP server for AI agents

Sync Socials runs a hosted MCP server. Point a compatible AI agent at it, and the agent can upload media, save drafts, schedule posts, publish, and check delivery on your connected social accounts. There is nothing to install or host.

Connection details

SettingValue
Endpoint https://app.sync-socials.com/api/mcp
Transport Streamable HTTP
Auth (API-key clients) Authorization: Bearer <SYNC_SOCIALS_API_KEY>
Auth (ChatGPT, Claude Chat and Cowork) Account authorization. No API key.
Plan API keys need an active trial or paid plan. Growth includes one active key. Agency includes three.
REST fallback https://app.sync-socials.com/api/v1, same bearer token, same limits

Your client must support remote Streamable HTTP and this authentication method. Not every agent or client version has been tested. A skill provides instructions; the client's own connection and tool support still determine what it can do.

Pick your connection

  • ChatGPT: connect the published app. No API key. See the ChatGPT setup guide.
  • Claude Chat and Cowork: install the plugin and use the custom connector. No API key. See the Claude setup guide.
  • Codex, Claude Code, OpenClaw and other API-key clients: use the steps below.

Connect an API-key client

  1. Start a trial or paid plan. API access needs one. You can explore and save drafts on a free account first. The trial needs a card, costs $0 today, then $19.95/month unless you cancel. See billing, the trial, and cancellation.
  2. Create a workspace API key. In Sync Socials, open Settings → API and create a key. Keep it in your agent's environment or secret storage, never in a prompt or a public repository. See agents and API keys.
  3. Add the server to your client. Use the config below. The server is remote, so there is nothing to run locally.
  4. Optional: install the agent skill. npx skills add DamianoTobasco/sync-socials-agent -g adds instructions for your agent. It does not connect your workspace by itself.
  5. Test with a draft. Ask your agent the prompt below. It needs no social account and no AI provider.

Generic config

{
  "name": "sync-socials",
  "transport": "streamable-http",
  "url": "https://app.sync-socials.com/api/mcp",
  "headers": {
    "Authorization": "Bearer <SYNC_SOCIALS_API_KEY>"
  }
}

OpenClaw

openclaw mcp set sync-socials '{"url":"https://app.sync-socials.com/api/mcp","transport":"streamable-http","headers":{"Authorization":"Bearer <SYNC_SOCIALS_API_KEY>"}}'

First prompt

Read my Sync Socials workspace, then create an untargeted draft titled “Getting started” with the caption “Our first post is coming soon.” Return its draft ID so I can open it in Sync Socials.

This uses syncsocials_get_workspace and syncsocials_create_content_draft.

Keep the key safe

The key grants read and write access to the workspace, including publishing, and has no automatic expiry. Replacing or revoking it affects every client using it. You can revoke it any time.

Prompts that work

  • Post this Reel to TikTok, Instagram, Facebook and YouTube Shorts at 6pm.
  • Queue five posts from the drafts folder across this week at 9am.
  • What is scheduled for the rest of the week? Move Friday's post to Saturday morning.
  • Check my X allowance, then save this caption as a draft for my connected X account.
  • Write three caption variants for this product photo and save them as drafts.

Scheduling uses the date, time and timezone you name. See how scheduling and publishing work and how timezones are applied.

Safety and limits

  • The skill defaults to drafts. It schedules or publishes only when you clearly ask.
  • Access is scoped to your workspace and to the accounts already connected in Connections.
  • Sync Socials never sees your social-network passwords. Accounts connect through each platform's official OAuth where supported. Telegram uses a bot token, and Discord and Slack use channel webhooks.
  • X publishing has its own allowance: up to 50 attempts per workspace per UTC month (up to 3 with links) and 10 per day. Each X account is limited to 30 per month and 3 per day. Failed attempts count. Check usage with syncsocials_get_workspace before a batch. See X limits.
  • Do not retry an unclear publish result automatically. Check the saved post and the destination first.
  • Reach and engagement depend on the platform, content, audience and timing, and are not guaranteed.

FAQ

What is a social media MCP server?

MCP, the Model Context Protocol, is an open standard that lets AI agents use external tools. A social media MCP server exposes things like media upload, drafting, scheduling and publishing as tools, so a compatible agent can run those steps from a plain-English prompt.

What is the Sync Socials MCP endpoint?

https://app.sync-socials.com/api/mcp, over Streamable HTTP. API-key clients send the key as a Bearer token in the Authorization header.

Do I need an API key?

For Codex, Claude Code, OpenClaw and similar clients, yes. ChatGPT and Claude Chat and Cowork connect with account authorization instead, with no API key.

Which AI agents work with it?

Any client that supports remote Streamable HTTP and the bearer-token auth should be able to connect. Setup is documented for ChatGPT, Claude Chat and Cowork, Codex, Claude Code and OpenClaw. Not every client version has been tested.

Can an MCP agent post to Instagram, TikTok and LinkedIn?

Yes, to accounts you have connected: linked Instagram professional accounts, TikTok, and LinkedIn personal profiles, plus Facebook Pages, YouTube, Telegram, Discord, Slack and X on an active paid Growth plan. LinkedIn company pages are not supported.

Does MCP access cost extra?

MCP and API access is included in the Growth plan at $19.95 a month or $199.50 a year, after a free 7-day trial. Some generation features use your own AI provider, which bills you separately.

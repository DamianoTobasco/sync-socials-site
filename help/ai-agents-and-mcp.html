Agents

Use Sync Socials from ChatGPT, Claude, or any MCP agent

Your agent can upload media, draft, schedule, publish, and check delivery, limited to the workspace you approve.

Three ways to connectWorkspace API keysWhat an agent can and can't do

Three ways to connect

  • ChatGPT: the published Sync Socials app. Sign in as the workspace owner and approve access; no API key needed. ChatGPT setup guide.
  • Claude Chat and Cowork: the published plugin with a custom connector. Claude setup guide.
  • API-key clients such as Codex, Claude Code, and OpenClaw: install the agent skill and configure a workspace API key against the hosted MCP server. Agent guide.

Workspace API keys

Create a key in Settings → API. The Growth plan includes one active key; revoking it stops every client using it immediately. Keep keys in the agent's environment, never in a prompt or a public repository.

What an agent can and can't do

  • It works only inside the workspace you approved and only with accounts already connected in Connections. Agent access does not connect social accounts for you.
  • Scheduling and publishing happen only when you ask. Drafts can be saved without a destination.
  • Disconnect an agent any time from Settings → Connected agents. Scheduled posts stay in the queue.

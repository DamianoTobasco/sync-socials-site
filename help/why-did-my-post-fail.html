Troubleshooting

Why did my post fail?

Every destination records its own result, so start by reading what the platform actually said.

Read the resultCommon causesRetry safelyStuck on processing

Read the result

Open Posted. Each post shows Delivered clean, Partial issues, or Needs review, with the platform's message under each destination. The Home page banner also shows recent failures.

Common causes

  • Needs reconnect: the platform token expired or was revoked. Reconnect the account in Connections; then retry.
  • Media rejected: wrong aspect ratio, too large, or an unsupported format for that platform. See the media requirements.
  • Caption too long for X, or missing the TikTok settings and music confirmation.
  • X allowance reached: publishing pauses until the daily or monthly reset.
  • Platform outage or rate limit: the worker retries temporary errors on its own; a post can show as processing for a while before it settles.

Retry safely

Retry failed on Posted re-sends only the destinations that failed; destinations that succeeded aren't sent again. Before retrying a destination whose result is unclear, check the platform itself for the post so you don't create a duplicate. If a platform confirms the post exists, use the reconciliation panel on Posted to mark it delivered instead of resending.

Stuck on processing

TikTok, Instagram Reels, and large video uploads finish on the platform's side after Sync Socials hands them over. A few minutes is normal. If a post is still processing after an hour, open it from Posted to see the latest status, and contact support with the post title if it doesn't settle.

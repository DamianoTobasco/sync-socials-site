FAQ

Agent questions, answered.

Can I use Sync Socials in ChatGPT?

The ChatGPT directory integration was submitted on September 11, 2026 and is awaiting approval. It is not yet publicly listed. The hosted MCP/API is available to compatible clients with a Sync Socials account and API access.

Which social platforms can my agent publish to?

TikTok, YouTube, LinkedIn personal profiles, Discord, Slack and Telegram are live. Facebook Pages and linked Instagram professional accounts work for eligible existing connections; general new-customer access is awaiting Meta approval. X/Twitter, Pinterest and LinkedIn company pages are not currently supported.

What is MCP and why does it matter for social media?

MCP, the Model Context Protocol, is an open standard that lets AI agents use external tools. Sync Socials exposes media upload, drafting, scheduling and publishing as MCP tools, so any compatible agent can run your social media accounts from a plain English prompt.

Which AI agents work with Sync Socials?

Codex, Claude Code, OpenClaw and other agents can connect when they support the hosted MCP/API and its authentication. The agent skill provides setup instructions and workflows. Client capabilities vary; use the agent documentation for setup.

Do I need to know how to code?

You do not need to write application code. Install the skill and configure a workspace API key in your agent environment. Then ask your agent to create drafts or schedule posts to the supported accounts you select.

Is it safe to let an AI agent post for me?

You control access through a workspace API key that you can revoke. Sync Socials does not ask for your social-network passwords. Social accounts use official OAuth where supported; Telegram uses a bot token, and Discord and Slack use channel webhooks. Ask the agent to create drafts for your review before scheduling or publishing.

What can the agent actually do?

Read workspace and brand context, list connected accounts and media, import media, generate concepts and videos, create or edit drafts, schedule or publish selected posts, reschedule or cancel planned posts, and check delivery status. Video generation may finish asynchronously.

Does agent access cost extra?

MCP and API access is included in the Growth plan at $19.95 a month or $199.50 a year, after a free 7 day trial. Some generation features require a configured AI provider and use that provider's allowance; provider charges are separate.

FAQ

Agent questions, answered.

What is MCP and why does it matter for social media?

MCP, the Model Context Protocol, is an open standard that lets AI agents use external tools. Sync Socials exposes media upload, drafting, scheduling and publishing as MCP tools, so any compatible agent can run your social media accounts from a plain English prompt.

Which AI agents work with Sync Socials?

Claude Code, OpenClaw, Codex and any agent that supports skills and MCP. If your agent can install a skill, it can run your Sync Socials workspace.

Do I need to know how to code?

No. You run one install command, paste your Sync Socials API key, and from then on you just talk to your agent. Post this to TikTok and Instagram at 9am is a complete workflow.

Is it safe to let an AI agent post for me?

Access is scoped to an API key you generate and can revoke at any time. Your social accounts connect through each platform's official OAuth login, and Sync Socials never sees your passwords. You can also have the agent create drafts for your approval instead of publishing directly.

What can the agent actually do?

Upload images and video, write and edit drafts, generate content concepts, schedule single posts or whole campaigns, publish to TikTok, Instagram, Facebook and YouTube, and inspect, reschedule or cancel anything in the queue.

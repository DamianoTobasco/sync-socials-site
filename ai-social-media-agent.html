FAQ

Agent questions, answered.

Can I use Sync Socials in ChatGPT?

Yes. Sync Socials is published in ChatGPT. Open the app listing, connect as your Sync Socials workspace owner, and approve access. Your workspace needs API access and eligible billing status; no workspace API key is required for account linking. Follow the ChatGPT setup guide.

Which social platforms can my agent publish to?

TikTok, YouTube, LinkedIn personal profiles, Discord, Slack and Telegram are live. Facebook Pages and linked Instagram professional accounts are available for new and existing customers. X/Twitter is live on active paid Growth subscriptions after the trial, with usage limits. Connect X through OAuth in Connections. Pinterest and LinkedIn company pages are not currently supported. Refresh your client’s tool list or installed Sync Socials instructions if it still says X is unsupported. Check current workspace capabilities and the X allowance before publishing. The published Claude plugin’s X instructions are awaiting an update; use the dashboard for X until that update is available.

What is MCP and why does it matter for social media?

MCP, the Model Context Protocol, is an open standard that lets AI agents use external tools. Sync Socials exposes media upload, drafting, scheduling and publishing as MCP tools, so any compatible agent can run your social media accounts from a plain English prompt.

Which AI agents work with Sync Socials?

Choose ChatGPT, Claude Chat or Cowork, or the API-key instructions for Codex, Claude Code, OpenClaw and compatible MCP clients. Setup and capabilities vary by client.

Do I need to know how to code?

You do not need to write application code. Use account authorization for ChatGPT or Claude Chat and Cowork. For API-key clients, install the skill and configure your key in the agent environment. Then create drafts or schedule posts to the accounts you select.

Is it safe to let an AI agent post for me?

You can revoke the connected-agent authorization or workspace API key in Sync Socials Settings. Sync Socials does not ask for your social-network passwords. Social accounts use official OAuth where supported; Telegram uses a bot token, and Discord and Slack use channel webhooks. Ask the agent to create drafts for your review before scheduling or publishing.

What can the agent actually do?

Read workspace and brand context, list connected accounts and media, import media, generate text concepts, create or edit drafts, schedule or publish selected posts, reschedule or cancel planned posts, and check delivery status. Media-generation capabilities vary by client: the Claude connector uses existing images and videos. Supported generation may finish asynchronously.

Does agent access cost extra?

MCP and API access is included in the Growth plan at $19.95 a month or $199.50 a year, after a free 7 day trial. Some generation features require a configured AI provider and use that provider's allowance; provider charges are separate.

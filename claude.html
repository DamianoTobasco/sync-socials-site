Claude Chat & Cowork

Schedule social media posts with Claude

Sync Socials has a plugin for Claude Chat and Cowork. Connect your workspace, and you can ask Claude to review your accounts, work with media you have already uploaded, save drafts, and schedule the posts you approve.

What Claude can do in your Sync Socials workspace

  • Show your workspace, connected accounts and scheduled posts
  • Browse your media library and attach existing images and video
  • Save a caption as a draft, with or without a destination
  • Write text campaign ideas from your business brief (needs an AI provider configured in Sync Socials)
  • Schedule or publish a post you have approved
  • Edit drafts, reschedule planned posts, or cancel a scheduled post before it goes out
  • Check the delivery result

The Claude connector uses images and videos you already have. It does not generate images, video footage, speech or music. Text ideas and captions are supported.

What you need

  • A Claude account with connector access. Organization settings can affect which connectors you can use.
  • A Sync Socials account. A free account can connect Claude. No trial, card or API key needed to connect.
  • The Owner role in that workspace, to approve the connection.
  • Connected social accounts before you schedule or publish. Untargeted drafts can be saved without them.

New to Sync Socials? Create your free workspace, then connect Claude. Claude access and your Sync Socials subscription are separate. A separate AI key is not needed just to save your caption, browse media, or edit a post.

Install the plugin and connect your workspace

The plugin adds the social-publishing workflow. Connecting your workspace is what gives it access to your accounts, media and posts. Until the directory listing is approved, connect with a custom connector:

  1. Add the plugin. Open the Sync Socials plugin in Claude and add it to your account.
  2. Add a custom connector. In Claude, open Customize → Connectors → Add custom connector. On Team or Enterprise, an Owner first adds it under Organization settings → Connectors → Add → Custom. Choose Web if asked.
  3. Name it and add the URL. Name it Sync Socials. Server URL: https://app.sync-socials.com/api/mcp
  4. Enter the OAuth client ID. Under Advanced settings, enter OAuth client ID e884049a-bc22-4239-9c82-8bdb7bf3a7b7 and leave the client secret blank. If Claude shows authentication choices instead, select Sign in now and Use your own OAuth client, then enter the same ID.
  5. Connect and approve. Add the connector, select Connect, and sign in with your workspace-owner account. On the Connect Claude screen, check the workspace name, email, requested access and return destination (claude.ai), then select Allow access. Choose Cancel to decline.
  6. Check the connection. Ask Claude to show the workspace it can access.

The client ID is a public identifier, not a password. No application secret or API key is needed. Never paste passwords, API keys or access tokens into a conversation.

If your workspace is already connected, keep that connection. Installing the plugin by itself does not connect your workspace. If the plugin's connector is unavailable or sign-in fails, contact support.

Start with a draft

Show my Sync Socials workspace, connected accounts, and scheduled posts. Do not change anything.
Save this caption as an untargeted Sync Socials draft: “A small update that makes the everyday easier.” Name it “Product update draft.” Do not schedule or publish it.

Campaign ideas from your brief

With an AI provider configured in your workspace (Viral Studio → Configure), Claude can write text ideas for review. See Content Studio and your own AI key.

Use my business brief to generate three campaign concepts in Sync Socials. Show me the hooks and captions for review. Do not produce media, schedule, or publish anything.

Concept generation can analyze and save a brand profile. It returns text ideas for review. Ask Claude to save the ones you like as drafts. Files attached in a Claude conversation are not added to your media library. Upload through the dashboard or give a downloadable HTTPS URL you are allowed to use. The hosted connector cannot read a file path on your computer.

Schedule or publish an approved post

Name the exact draft, the destination accounts, the date, the time and the timezone. Review the caption, media and any platform privacy or disclosure choices first. See how scheduling and publishing work and how timezones are applied.

Schedule the approved “Product update draft” to the account I selected on October 15, 2026, at 2:30 p.m. America/New_York. Keep its approved caption and media unchanged. Show me the saved schedule afterward.

To publish now, ask Claude to publish the approved post to the accounts you name. Saving a draft never publishes. Claude may ask you to confirm a tool action before it changes anything.

After it is scheduled

Check the delivery result. Queued or processing is not necessarily live. If one destination reports an error, review it before retrying. Canceling deletes the queued Sync Socials post; it does not remove content already published on a social network.

Claude Code and other agents

This plugin is for Claude Chat and Cowork. It does not support direct Claude Code authentication. If you use Claude Code, Codex or OpenClaw, connect with a workspace API key instead. See the Sync Socials MCP server guide.

A connector provides tools; it does not guarantee recommendations or that Claude will select Sync Socials for every request. For the plain-English overview of every option, see For AI agents.

Your access and control

  • Account linking does not share your social-network passwords or Sync Socials API keys with Claude.
  • Content the connector returns is available to Claude to handle your request. Concept generation sends relevant brand context to the AI provider configured in your workspace.
  • To disconnect, open Settings → Connected agents, select Disconnect Claude, then remove Sync Socials from Claude's connector list.
  • Existing drafts and scheduled posts stay. Cancel unwanted schedules separately. Your ChatGPT connection is not affected.

Claude can use the Sync Socials workspace you approve. Its tools can read workspace and brand information, connections, media, posts, and usage; import media; and create or change content, schedules, and publishing requests. See the Sync Socials Privacy Policy and how agents and MCP access work. Claude's own settings, terms, and policies also apply.

Disconnect Claude

  1. Open Sync Socials Settings → Connected agents.
  2. Find Claude and select Disconnect Claude.
  3. Remove Sync Socials from Claude's connector list if you no longer want it there.

Disconnecting stops further access through that authorization. Your social accounts stay connected. To reconnect, start a new connection from Claude and approve the intended workspace again.

Troubleshooting

The plugin is installed but the connector is unavailable

Installing the plugin does not connect your workspace by itself. Follow the custom connector steps above.

Only the owner can connect, or the subscription has ended

Sign in with the workspace-owner account. If the consent screen says the subscription has ended, renew it in Billing and connect again.

The connection is invalid, expired or needs reconnecting

Start again from Claude. If the error asks you to disconnect a previous authorization, disconnect Claude under Connected agents first, then retry.

No accounts or media appear

Check you approved the right workspace. Connect an account or upload media in Sync Socials, then ask Claude to refresh the list.

A provider key, usage limit, or media error appears

Configure concept-generation providers in Sync Socials under Viral Studio → Configure. Check workspace usage when a limit is reached. For processing media, check the post again; for a failed URL import, upload the file through the dashboard instead.

For help, email contactsyncsocials@gmail.com with the error, time, and affected workflow. Do not include passwords, API keys, OAuth secrets, or access tokens.

FAQ

Can I schedule social media posts with Claude?

Yes. Install the Sync Socials plugin for Claude Chat or Cowork, connect your workspace, then name the post, accounts, date, time and timezone. Drafting is free. Scheduling and publishing start with the 7-day free trial.

Do I need an API key to use Sync Socials with Claude?

No. Claude connects through account authorization. You sign in as the workspace owner and select Allow access. The OAuth client ID in the setup steps is public.

Does it work with Claude Code?

Not through this plugin. The plugin is for Claude Chat and Cowork. Claude Code connects with a workspace API key through the hosted MCP server.

Can Claude create images or videos for my posts?

No. The Claude connector works with images and videos you already have in your media library. It can write captions and text campaign ideas.

Is it free to connect Claude to Sync Socials?

Yes. A free account can connect Claude, show your workspace and accounts, and save drafts. Scheduling and publishing start with the 7-day trial, which needs a card, costs $0 today, then $19.95/month unless you cancel.

Which social platforms can Claude post to?

TikTok, YouTube, LinkedIn personal profiles, Facebook Pages, linked Instagram professional accounts, Bluesky, Telegram, Discord and Slack. Threads is available in workspaces where Threads access is enabled. X/Twitter is live in Sync Socials on an active paid Growth plan, but the published Claude plugin's X instructions are awaiting an update, so use the dashboard for X for now. Pinterest and LinkedIn company pages are not supported.
